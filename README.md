# Nile Stone Café – نايل ستون كافيه

موقع الكافيه: جنينة على النيل في منيل الروضة / مصر القديمة، ومكان للمناسبات الخاصة.

موقع ثابت بيتولد من ملفات في `src/`. مفيش أي مكتبات ولا سيرفر، ومحتاج Node.js بس.

## الصفحات (عربي على الجذر، وإنجليزي تحت `/en/`)
| الرابط | الصفحة |
|---|---|
| `/` | الرئيسية |
| `/menu/` | المنيو كامل بالأسعار. دي صفحة الـ QR اللي على الترابيزات |
| `/romantic-date/` | رومانتيك ديت (من 800 ج.م لفردين) |
| `/engagement/` · `/katb-ketab/` · `/birthday/` · `/gatherings/` | المناسبات (من 2500 ج.م) |
| `/girls-night/` | حفلة البنات الشهرية (التذكرة 200 ج.م) |
| `/faq/` | الأسئلة الشائعة |

## تعديل المحتوى
كل المحتوى في ملفين:
- **`src/data.mjs`:** الإعدادات (الدومين، الرقم، العنوان، المواعيد، الأسعار)، والمنيو، والأسئلة الشائعة، وأنواع المناسبات، والصور.
- **`src/content.mjs`:** نصوص الصفحات بالعربي والإنجليزي.

بعد أي تعديل، شغّل الأمر ده وارفع الملفات اللي اتغيرت:
```bash
node src/build.mjs
```

### حاجات مهمة تتغير في `src/data.mjs`
- `url`: الدومين الحقيقي بعد ما يتشترى. **لازم يتغير قبل ما الموقع ينزل**، لأن جوجل والسوشيال بيقروه.
- `girlsNextDate`: ميعاد حفلة البنات الجاية، مثلًا `"2026-10-16T19:00"`. أول ما يتكتب، الميعاد بيظهر في الموقع وبيتبعت لجوجل كـ Event. سيبه `null` لو مفيش ميعاد محدد.
- `geo` و `mapsUrl`: إحداثيات المكان ولينك Google Maps. بيتحطوا بعد ما صفحة Google Business تتعمل.

## السيو والجيو والأيو (SEO / GEO / AEO)
- **صفحة لكل خدمة:** كل صفحة ليها عنوان ووصف ورابط خاص، بالعربي والإنجليزي، ومربوطين ببعض بـ `hreflang`.
- **بيانات منظمة (Schema.org JSON-LD):**
  - `CafeOrCoffeeShop` + `EventVenue`: الاسم والعنوان والمواعيد والسعة والمميزات.
  - `Menu`: فيه كل الأسعار.
  - `Service`: لكل مناسبة، بالسعر اللي بتبدأ منه.
  - `FAQPage` و `BreadcrumbList`.
  - `Event`: لحفلة البنات، لما يكون ليها ميعاد.
- **`llms.txt`:** ملخص فيه كل المعلومات الأساسية، مكتوب عشان مساعدين الذكاء الاصطناعي (ChatGPT وClaude وPerplexity وGemini).
- **`robots.txt`:** بيسمح صراحةً لبوتات البحث والذكاء الاصطناعي.
- **`sitemap.xml`:** فيه كل الصفحات باللغتين.
- **الأداء:** صور WebP بأبعادها الحقيقية عشان الصفحة ماتتهزش وهي بتحمّل، والصور بتتحمّل وقت ما توصلها بس، ومفيش مكتبات تقيلة.

## التشغيل على جهازك
```bash
node src/build.mjs
python3 -m http.server 8000   # افتح http://localhost:8000
```

## الرفع
الأفضل **Cloudflare Pages** أو **Netlify** مع الدومين، وده من غير أمر build، لأن الملفات الجاهزة موجودة في الريبو. لو استخدمتوا GitHub Pages، استخدموه بدومين خاص عشان صفحة 404 تشتغل صح.
